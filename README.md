# ESP32-Negator
## What it is
ESP32-Negator is a DoS Wi-Fi jammer. It works by completely flooding the 2.4Ghz band with fake beacons to cause an extreme amount of radio noise. 

**Strengths:**
Completely blocks communication on the 2.4Ghz band  
**Weakness:**
Has no effect on 5Ghz and 6Ghz Wi-Fi bands
## How to use
1. Connect the ESP32 to a power supply (Micro-USB)
2. To turn on the jammer, hold down the __BOOT__ button for 2 seconds. 
3. Wait for the LED to turn on. When the LED turns on, it meand that the jammer has started jamming.
4. To turn off the jammer, press the __EN__/__RST__ button or disconnect the power supply.
